Exercises

Each lesson's key functions with the bodies removed and the tests left in. Read the post, then make the tests pass.

The exercise copies live in clojure/ex/exercises/lessonNN and go/exercises/lessonNN; each blank is a TODO that throws, with a hint above it. At a REPL: clj -A:ex, then (require 'exercises.lessonNN.ns-test :reload) and (clojure.test/run-tests 'exercises.lessonNN.ns-test). The reference lessons are the answer key.
