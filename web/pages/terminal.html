Terminal

The Go programs from this series, compiled to WebAssembly and running in your browser. Nothing runs on a server.

Loading terminal… (this page needs to be served over HTTP: it loads WebAssembly. Locally: tools/build_wasm.sh && uv run python -m http.server -d docs)

The binaries are the unmodified go/cmd/* programs built with GOOS=js GOARCH=wasm. They read stdin and write stdout as usual; assets/terminal.js supplies the fs object Go's js/wasm runtime calls for I/O, so a read on stdin waits for you to press Enter. The terminal is ghostty-web: Ghostty's VT emulator compiled to WebAssembly.
