# {{TITLE}}

A learning project built on [learning-kit](https://github.com/dpsutton/learning-kit): interactive
posts, a toy implementation in Clojure and Go, an exercise track, recall cards, real-world source
excerpts, and the Go programs running in the browser.

```bash
lk serve        # build the site and open http://localhost:8000
lk exercises    # regenerate the exercise track after editing EXERCISE markers
lk ci           # everything CI checks
```

Content lives in `learning.json`, `site/` (posts, figures, cards, excerpts), `clojure/`, and `go/`.
